# Report investigation task

For each assigned report, answer only from the self-contained HTML:

1. Which two keys have a required difference in `status`?
2. Which key has a required difference in `note`?
3. Which key is baseline-only, and which is candidate-only?
4. How many `amount` differences are within tolerance?
5. Would you release this candidate? Give one sentence explaining why.

Follow the facilitator's instruction about whether report filter controls are allowed for this report. Do not inspect the CSV, recipe, result JSON or the other study files.
